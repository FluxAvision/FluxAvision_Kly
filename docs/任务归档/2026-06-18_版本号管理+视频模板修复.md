## 任务二：视频模板渲染白屏修复 + 动态指标

### 问题

选择视频模板后页面白屏，只有背景色。

### 根因

两个问题：

1. **LargeScreenApp.vue 缺失 VideoTemplate**：独立大屏页面入口 `src/LargeScreenApp.vue` 没有 import VideoTemplate、`isBuiltinTemplate` 未包含 `'tpl-video'`、没有渲染 v-if。
2. **VideoTemplate.vue 内部 ReferenceError**：`cardColorClass` 函数引用了未定义的 `config` 变量（应为 `props.config`），导致模板渲染崩溃。

### 改动文件

| 文件 | 操作 | 说明 |
|------|------|------|
| `frontend-vue/src/LargeScreenApp.vue` | 修改 | import + isBuiltinTemplate + v-if 渲染 VideoTemplate |
| `frontend-vue/src/components/large-screen/templates/VideoTemplate.vue` | 新建 | 修复 cardColorClass + 重写 metricRows 动态逻辑 |

### 技术要点

- Vue 3 `<script setup>` 中 setup 函数引用变量必须先声明或通过 `props.` 访问
- `onErrorCaptured` 只捕获子组件错误，不捕获当前组件的渲染错误
- v-for 中调用模板函数如果函数内引用未定义变量，整个渲染崩溃
- 函数参数改为简单类型（number index）避免依赖父作用域未定义变量
