# 前端 3000 端口排查报告

**时间：** 2026-05-28 22:23
**排查人：** FA_KLY

---

## 1. 现象

`http://192.168.1.2:3000` 无法访问，浏览器提示连接失败。

## 2. 排查过程

### 2.1 检查进程监听

```powershell
netstat -ano | findstr ":3000 "
```

**结果：** Vite dev server 已在运行（PID 5820），但监听地址为：

```
TCP    [::1]:3000    [::]:0    LISTENING    5820
```

**关键发现：** 服务器**只监听在 IPv6 回环地址 `[::1]:3000`**，未监听 `0.0.0.0`（即所有网络接口）。

这意味着：
- `http://localhost:3000` → **可访问**（本机 localhost 解析到 `::1`）
- `http://127.0.0.1:3000` → **不可访问**（本机实际解析到 IPv4 localhost，与 `::1` 不直通）
- `http://192.168.1.2:3000` → **不可访问**（未绑定 LAN 网卡）

### 2.2 验证确认

| 地址 | 修改前 | 修改后 |
|------|--------|--------|
| `http://localhost:3000` | ✅ 200 | ✅ 200 |
| `http://127.0.0.1:3000` | ❌ 000 (连接失败) | ✅ 200 |
| `http://192.168.1.2:3000` | ❌ 000 (连接失败) | ✅ 200 |

### 2.3 检查 vite.config.ts

`frontend-vue/vite.config.ts` 中 server 配置：

```typescript
server: {
  port: 3000,
  // ❌ 缺少 host 配置
}
```

Vite 默认 `host` 为 `localhost`，因此只监听回环地址，不暴露到局域网。

## 3. 根因

**Vite dev server 的 server.host 未配置。**

`vite.config.ts` 中只指定了 `port: 3000`，缺少 `host: '0.0.0.0'`，导致 Vite dev server 默认只监听 `localhost`（IPv6 `::1`），局域网其他设备无法访问。

## 4. 修复方案

### 4.1 修改 vite.config.ts

在 `server` 配置中添加 `host: '0.0.0.0'`：

```typescript
server: {
  host: '0.0.0.0',   // ✅ 新增：监听所有网络接口
  port: 3000,
  proxy: {
    '/api': {
      target: 'http://127.0.0.1:15678',
      changeOrigin: true,
    },
  },
},
```

### 4.2 重启 Vite dev server

```powershell
# 停止旧进程
taskkill /F /IM node

# 重新启动
cd D:\FluxAvision\FluxAvision_Kly\frontend-vue
npm run dev
```

### 4.3 验证命令

```powershell
# 本机验证
curl.exe http://localhost:3000/

# LAN 验证（在本机或其他 LAN 设备上执行）
curl.exe http://192.168.1.2:3000/
```

预期返回 `HTTP 200`。

## 5. 防火墙备注

本次排查未发现防火墙拦截（进程正常绑定端口）。如果其他端口遇到类似问题，可用以下命令放行：

```powershell
netsh advfirewall firewall add rule name="Vite Dev" dir=in action=allow protocol=tcp localport=3000
```

## 6. 处理结果

- ✅ 根因已定位：vite.config.ts 缺少 `host: '0.0.0.0'`
- ✅ 修复已应用：已添加 `host: '0.0.0.0'` 并重启 dev server
- ✅ 验证通过：`http://192.168.1.2:3000/` 返回 HTTP 200
- 当前 Vite dev server PID：17472，监听 `0.0.0.0:3000`
